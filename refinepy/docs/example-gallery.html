Numerical playground examples

The menu contains one basic contract and five numerical examples. The central question is what equation or inequality the computed number must satisfy. All accepted samples are copied from maintained Python sources. Select * to verify their implementation and helper functions together.

Example Numerical guarantee

Integer square root

For 27, the result is 5 because 25 <= 27 < 36. For 36 it is 6. For 0 it is 0. integer_sqrt repeatedly halves a numerical search interval instead of scanning possible roots. Its loop invariant brackets the answer with lower*lower <= n < upper*upper; the decreasing interval width establishes termination. At the end the interval contains adjacent integers, giving the return contract. No upper bound on the nonnegative input appears in the contract.

Try returning lower + 1. This breaks the square-root inequality. The loop uses an explicit continue on the lower-bound branch to keep its two back edges separate; this avoids an additional inferred join in the current checker. Source: examples/numeric/square_root.py.

Accumulation agrees with a formula

sum_to(4) accumulates 1 + 2 + 3 + 4 and returns 10. Its contract proves 2*10 == 4*5, the closed-form identity, for every nonnegative input. The loop invariant relates the running total to the current index, and n - i decreases. The empty sum at zero is included.

sum_between(3, 6) returns 15, the sum of 4, 5 and 6. It composes two checked prefix sums and guarantees 2*result == upper*(upper+1) - lower*(lower+1) for 0 <= lower <= upper. Try replacing total += i with total += 1; the invariant is no longer preserved. Source: examples/numeric/series.py.

Exact rounding and rescaling

round_ratio(7, 3) returns 2. round_ratio(5, 2) returns 3, and round_ratio(-5, 2) returns -2: ties go toward positive infinity, not toward zero, away from zero or to the nearest even integer. For positive denominator d and numerator n, its contract is

(2*r - 1)*d <= 2*n < (2*r + 1)*d

This specifies the nearest integer and the tie boundary without floating-point operations. rescale(value, factor, denominator) first multiplies exactly and uses the checked rounding contract. For example, rescale(125, 3, 2) returns 188. Such scaling appears in unit conversion and fixed-point arithmetic; this example models unbounded integers, not machine overflow or a financial rounding policy. Try subtracting one from the division numerator: positive half-way cases round the wrong way. Source: examples/numeric/rounding.py.

Fibonacci

The ordinary recurrence specifies the answer; fast doubling computes it through smaller indices. An inductive addition lemma derives the doubling identities. fast_fib guarantees result == fib(n) for every nonnegative index, rather than only promising a nonnegative result. Its proof calls are erased at the static assertion site. No runtime complexity or resource guarantee is claimed. Source: examples/fibonacci/fibonacci.py.

Signed division

divide(-7, 3) returns quotient -3 and remainder 2, satisfying -7 == (-3)*3 + 2 and 0 <= 2 < 3. A negative divisor instead requires d < remainder <= 0. The divisor must be nonzero. These bounds distinguish Python floor division from truncation toward zero. Source: examples/practical/division.py.

Other examples and validation

Sorting, binary search over lists, framing, partitioning and local list updates remain maintained repository examples and regression cases, but no longer occupy the menu. The short contract exercises also remain available. The menu prioritizes numbers rather than container representations.

The numeric sources are checked by the native CLI and the Wasm regression suite. The square-root and summation edits report unproved; the rounding edit reports counterexample. A separate finite Python check uses math.isqrt, explicit summation and Fraction as independent oracles and executes the three edited implementations on concrete witnesses. Static unproved outcomes remain distinct from these separately observed failures. Verification assumes the input refinements and modeled runtime; ordinary Python calls do not enforce contracts, and termination does not prove resource safety.
