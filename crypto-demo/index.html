WebCryptoでの公開鍵暗号・署名デモ

ブラウザ内だけでメッセージを暗号化・復号します。

使い方

  1. 「鍵を作る」で鍵ペアを作成し、公開鍵と秘密鍵を保存します。
  2. 暗号化してもらう相手に公開鍵を渡します。秘密鍵とパスフレーズは渡さないでください。
  3. 相手は公開鍵でメッセージを暗号化し、暗号文をあなたへ送ります。
  4. 受け取った暗号文を秘密鍵で復号します。設定した場合はパスフレーズも入力します。

暗号処理は WebCrypto API で行います。入力内容や鍵を送信するコードはありません。GPG / OpenPGP との互換性はありません。

鍵を作る

設定する場合は10文字以上を推奨します。空欄の場合、復号時と署名時も空欄にします。
